---
title: API tokens
description: Authenticate every request to the API.
---
Tokens identify your account to the API. Create one for each app or script that calls the API, so you can revoke it on its own.

Every request needs a <Tooltip tip="A secret key sent with each request to prove who is calling. Keep it out of client-side code." headline="Bearer token" cta="Create a token" href="/quickstart">bearer token</Tooltip> in the `Authorization` header.
