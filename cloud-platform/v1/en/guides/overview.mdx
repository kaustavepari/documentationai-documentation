## Get started with Cloud Platform

Cloud Platform is a scalable deployment platform for modern web applications. Deploy applications across regions, scale them as traffic changes, and rely on managed security controls built into the platform.

## Quick Architecture

Cloud Platform routes requests through an edge network before they reach your application tier. The edge network handles global traffic distribution and helps reduce latency for users in different regions.

Your application tier connects to a managed database, which handles persistence without requiring you to operate database infrastructure directly. This separation lets you scale application capacity independently from data storage.
