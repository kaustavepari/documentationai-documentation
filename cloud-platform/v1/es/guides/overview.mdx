## Comienza con Cloud Platform

Cloud Platform es una plataforma de despliegue escalable para aplicaciones web modernas. Despliega aplicaciones en diferentes regiones, escala según el tráfico y confía en los controles de seguridad integrados.

## Arquitectura Rápida

Las solicitudes entran por la red perimetral, que las dirige al nivel de aplicación más cercano y disponible. Este nivel ejecuta tus servicios y escala horizontalmente según la demanda.

El nivel de aplicación se conecta a una base de datos gestionada. Cloud Platform administra la disponibilidad, las copias de seguridad y la protección de los datos.
